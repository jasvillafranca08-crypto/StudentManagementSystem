# StudentHub – Student Information Management System

## Project Description

StudentHub is a PHP-based Student Information Management System developed for Activity 9. It helps organize, display, and manage student information through a simple and user-friendly interface.

## Features

- Dashboard with dynamic statistics
- Student records management
- Search students by ID, name, or course
- Add student records
- Edit student information
- Delete student records
- View individual student details
- Success and error notifications
- Black & White user interface

## Technologies Used

- PHP
- HTML5
- CSS3
- JavaScript
- XAMPP (Apache)
- GitHub

## PHP Concepts Implemented

- Associative arrays
- PHP functions
- Foreach loops
- Conditional statements
- String functions
- Array functions
- PHP sessions
- GET and POST methods
- Form validation

## Installation

1. Install XAMPP.
2. Copy the project folder into `htdocs`.
3. Start Apache.
4. Open your browser.
5. Visit:

`http://localhost/StudentManagementSystem/`

## Data Storage

The application uses PHP associative arrays and sessions to manage student records. Data is maintained during the active session and is not permanently stored in a database.

## Project Structure

- `index.php` – Dashboard
- `students.php` – Student records
- `add_student.php` – Add student
- `edit_student.php` – Edit student
- `delete_student.php` – Delete student
- `student_details.php` – Student details
- `includes/functions.php` – PHP functions and student data
- `css/style.css` – Application styling
